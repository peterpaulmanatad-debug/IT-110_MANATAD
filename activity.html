Hyperlinks

Hyperlinks are used to connect webpages and other resources. They allow users to navigate to another page, visit an external website, send an email, or move to a specific section of the same page.

Multimedia

HTML5 provides built-in elements for displaying multimedia. Audio and video can be added directly to a webpage without requiring additional plugins.

Audio

The audio element allows sound files to be played directly through the browser using built-in playback controls.

Video

The video element allows video files to be displayed and controlled directly within the webpage.

HTML DOM

The HTML Document Object Model, or DOM, represents an HTML document as a hierarchical tree of elements. Each element can have a parent, children, or both.
